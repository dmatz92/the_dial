Step 1 · Connect a Firebase project
One-time setup (~10 min), free tier, only you can access your data once this is done.
  1. Go to console.firebase.google.com and create a project (Analytics can stay off).
  2. Click the </> (web app) icon to register a web app, then copy the firebaseConfig object it shows you.
  3. In the left menu: Build → Authentication → Get started, then enable the Email/Password sign-in method.
  4. In the left menu: Build → Firestore Database → Create database. Any region is fine.
